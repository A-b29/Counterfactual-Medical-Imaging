# Sample Data Documentation & Provenance

The images in this directory are procedurally generated synthetic phantoms created by `src/sample_generator.py`.

- **License:** CC0 (Public Domain / Synthetic Generation)
- **Modality:** Simulated Digital Radiography (DX) & Epiluminescence Microscopy
- **Patient Privacy:** Contains zero real patient health information (PHI/PII). Generated via mathematical geometric primitives with physical tissue scattering simulation.
